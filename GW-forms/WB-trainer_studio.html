📘 About BookMaker Trainer

This training manual explains the core components of the BookMaker system. Use this as a reference to understand how to configure, style, and structure your manuscript.

⚙️ Config Registry

Lists all available configuration tags that control book metadata, colors, pagination, and display options. Each tag is defined in the CONFIG_SCHEMA and can be placed at the top of your .md file.

🎨 TOBj

TOBj (Text Object Builder) is a powerful styling syntax that allows you to apply inline, block, and inline-block styles to any text or paragraph. The REG_ATTR registry defines all available TOBj items, grouped by type (block, inlineblock, inline) and category (alignment, background, spacing, typography, etc.).

📝 Markdown

BookMaker supports a superset of Markdown, including tables, lists, headings, emphasis, and custom tags. Learn which HTML tags are supported, how to use Chapter and Section markers, and how to structure your manuscript for automatic pagination and TOC generation.

🎨 TOBj – Text Object Builder

TOBj is a styling syntax that lets you apply CSS styles to text. The format is:
{[ item1; item2; ... ]} [[Your text]]

Items can be block (__), inline-block (__i), or inline (_) styles. Some items accept parameters: _color(red), _fontsize(1.5), __bgcolor(#ffeeee).

Examples:

  • {[_bold; _color(#e74c3c)]} [[Important text]]
  • {[__bgcolor(#f0f0f0); __padding(1rem); _italic]} [[Highlighted paragraph]]
  • {[_fontsize(1.8); _fontfamily(Georgia); __center]} [[Chapter Title]]
