• BookPgColor – Content page background
• CoverBgColor – Cover page background

• TOCFontColor – Table of Contents text color (optional – auto‑generated)
• BookFontColor – Main book text color (optional – auto‑generated)
• HighlightTextFontColor – Highlighted text color

{[_bold]}[[BookTitle]]<nl>

{[_bold]}[[AuthorName]]<nl>

• Tag: {[_italic]}[[&lt;AuthorName='…'&gt;]]

{[_bold]}[[BookDescription]]<nl>

• Keep to 1-2 sentences for best visual effect.<nl>
• Tag: {[_italic]}[[&lt;BookDescription='...'&gt;]]

{[_bold]}[[MetaDescription]]<nl>

{[_bold]}[[WordsPerPage]]<nl>

{[_bold]}[[CoverBgColor]]<nl>

• Use hex <i>#RRGGBB</i>, named colors, or RGB values.<nl>

{[_bold]}[[TOCAsList]]<nl>

{[_bold]}[[CoverPageSkip]]<nl>

{[_bold]}[[ShowBookListLink]]<nl>

• Tag: {[_italic]}[[&lt;ClearGlassPanel&gt;]]<nl>
• <b>Example:</b> Place <i>&lt;ClearGlassPanel&gt;</i> on a page with an image to show it without the glass overlay.

• Tag: {[_italic]}[[&lt;NewPage&gt;]]

{[_bold]}[[Section]]<nl>

• Takes no styling – purely structural.<nl>

{[_bold]}[[SectionTitle]]<nl>

• Tag: {[_italic]}[[&lt;SectionTitle='Section Title'&gt;]]

{[_underline; _bold]}[[QUICK RULES]]

• <b>Order:</b> Settings (Pages 1-4) must come before <i>&lt;StartBook&gt;</i><nl>
• <b>Quotes:</b> Use double quotes (") if value contains single quotes ('), e.g., <i>&lt;BookTitle="O'Reilly Book's"&gt;</i><nl>
• <b>Colors:</b> Use hex <i>#RRGGBB</i>, named colors, or RGB values<nl>
• <b>Images:</b> Must be <i>.jpg</i> or <i>.jpeg</i> in same directory as output HTML<nl>
• <b>Booleans:</b> Use <i>True</i> or <i>False</i> (case-insensitive)<nl>
• <b>Inline Styling:</b> Use <b>&lt;b&gt;...&lt;/b&gt;</b> for <b>bold</b>, <i>&lt;i&gt;...&lt;/i&gt;</i> for <i>italic</i>, and <u>&lt;u&gt;...&lt;/u&gt;</u> for <u>underline</u> in your content<nl>
• <b>Chapter numbering:</b> Auto-numbered <i>1</i>, <i>2</i>, <i>3</i>...<nl>
• <b>Section numbering:</b> Auto-numbered <i>1.1</i>, <i>1.2</i>, <i>2.1</i>, <i>2.2</i>...<nl>
• <b>TOBj Styling:</b><nl>
